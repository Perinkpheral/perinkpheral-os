1. First start

perINKpheral shows time, weather and other information on an e-paper screen. There is no backlight. Read it in room light. A brief flash when the picture changes is normal.

If you are installing firmware for the first time, use the web flasher with the device connected by USB. A fresh install erases existing data. Wait for flashing and restart to finish: the Wi-Fi setup screen with its QR code appears automatically. Continue below.

  1. Connect a USB-C cable to a USB power supply or a computer. The device starts and charges its battery. It can run without the cable when charged.
  2. On your phone, scan the QR code on the screen and join Perinkpheral-XXXX. You can also choose that network in the phone's Wi-Fi settings. Stay connected even if the phone says there is no internet.
  3. Open the setup page offered by your phone. It may take a little while to appear. If it does not, open http://192.168.4.1 in a browser.
  4. Open Settings > Network. Click Scan networks, choose your home network, enter its password and click Connect. Use a 2.4 GHz Wi-Fi network. Confirm with OK on the device when it asks to join.
  5. After the restart, reconnect your phone to the same home network. Hold BACK for about a second and release it to open the menu. Select About with UP or DOWN and press OK to open it. Press OK again for its second page. Open the address shown there in your browser. Bookmark this device page.

When the page asks for confirmation on the device, press OK within one minute. BACK cancels. If the request expires, repeat the action on the page.

If joining fails for two minutes, the device offers its setup network again. Join it and check the network name and password.

A new device starts in English. To change it, open Settings > Language on its page, choose your language and click Save. Install Cyrillic there for Russian letters on the screen.

You can now open the applications already installed from the menu. Some need settings in Installed apps on the device page (section 3).

2. Installing applications

Eight applications are already installed: Weather, Clock, ISS, Calendar, Timer, Stopwatch, Stocks and Air quality. Open them from the device's menu or configure them in Installed apps on its page. Use Catalog to add more. The device downloads them itself.

  1. Open the device page from a phone or computer on the same Wi-Fi network. Choose Catalog and read the application's description.
  2. Click Install and wait for completion. A newly installed application opens on the device and appears in its menu. If asked to install a system app, confirm with OK on the device.
  3. Open Installed apps to manage your applications. The information icon on a tile shows its connections and access. Click Update when offered. Update all appears when at least two compatible updates are available. Updates keep settings and the current screen.
  4. To remove an application, click Remove and confirm in the browser. Removing an application also deletes its files. Its settings are kept for a later installation; they may be cleared if the device needs space.

Keeping applications current

Turn on Auto-update in Installed apps to check daily, including while the device page is closed. It updates installed applications without adding new ones or granting new access. Updates requiring new access or changed certificate authorities need a manual update. If an application needs newer firmware, update the firmware first (section 6).

The official catalog is already included. The gear at the upper right of Catalog opens Sources. Press +, enter the publisher's catalog address and click Save. The official source stays first. If several sources contain the same application, the first source containing it is used.

3. Setting up applications

In Installed apps, click the gear on an application. Fill in its settings and click Save. Each application has its own fields. Some work immediately and have no settings.

Places and lists

For a place, start typing its name and choose the matching result from the list. Typing a name alone is not enough. Place suggestions require internet access on your phone or computer. For a list, press + to add a row and - to remove one. Save when finished.

Companion pages

Some applications offer Set up in their settings. It opens a separate page for choosing data or connecting a service. Allow the pop-up if your browser blocks it. Follow that page's steps, then return to the device page and click Save to save the received settings.

When the screen says Not set up

The application needs information you have not supplied yet, such as a place, a list or a service address. Open its settings on the device page, complete them and save. It is installed already; you do not need to install it again.

A saved password or token is not shown again. Leave its field unchanged to keep it. Changing an existing service address clears the application's saved passwords and tokens, so enter the credentials for the new address before saving. Some address fields have a Remove button. Click it, then Save, to clear that address.

4. Device settings

Hold BACK for about a second and release it to open the menu. Select Settings with UP or DOWN and press OK. Select a section, then a setting, with UP/DOWN and OK. In a value picker, UP/DOWN changes the selection, OK saves and BACK cancels. Automatic switches immediately when you press OK. For a confirmation, OK proceeds and BACK cancels.

SettingWhat it does
General Date, time, time zone and power saving. With automatic time off, set the clock by hand: UP/DOWN change a field, OK moves to the next, BACK to the previous. OK on the last field saves; BACK on the first cancels.
Apps Remove an installed application.
Appearance Font, clock in header, default app and idle timeout. The default app opens after restart and when you leave the menu idle. With Default app set to None, a restart opens the last application if it is still available, otherwise the menu, unless Wi-Fi setup is required. The menu then stays open when idle.
Display Refresh interval limits automatic screen refreshes, not data downloads. Full refresh controls routine cleaning of faint traces. Forced refresh cleans the screen after the selected time without a refresh. Fast refresh shortens full refreshes. Changing applications can still cause a full refresh.
Wi-Fi Network and address. Forget network asks for confirmation, deletes the saved network name and password, turns Wi-Fi off and restarts the device. Connect to Wi-Fi restarts it into Wi-Fi setup.
Restart / Reset Restart keeps your settings. Reset erases device settings, application settings and saved application values, then starts Wi-Fi setup. Installed applications and application-created files stay. Both ask for confirmation.

Power saving: Disabled keeps Wi-Fi and the page available. Always saves power between data requests. Auto saves when no computer is connected by USB; a USB charger is treated like battery operation. While saving, each scheduled data refresh has an interval of at least five minutes. Manual refreshes can run sooner.

More on the device page

Settings also lets you change the device name, enter a Wi-Fi password, set the time server, choose a language and manage character packs in Language. Install Cyrillic for Russian letters; without it, the device spells words in Latin letters. Installing character packs also requires internet access on your phone or computer. Settings > Log controls logging preferences. The main Log section displays the entries. Use Device for status, restart, recovery and factory reset. Factory reset requires confirmation in the browser and then OK on the device.

With power saving, the page may be unavailable between requests for data. Press a button to keep it reachable for two minutes. With Wi-Fi off, use Settings > Wi-Fi > Connect to Wi-Fi on the device.

5. Gestures and buttons

A short press is a tap. For a long press, hold for at least 0.6 seconds - about a second is enough. The screen takes a moment to change; wait for it before pressing again.

ButtonWhat it does
UP / DOWN Move through a menu or change a value. A long press moves a page in menus and Settings. Applications may use these buttons differently.
OK Open the selected row or confirm a choice.
BACK Go back within an application, or leave it. In the menu, open the default app if one is chosen.
Long BACK Open the menu when you release BACK.

Switch applications: while an application is open, hold BACK and tap UP for the previous application or DOWN for the next, in menu order. Keep BACK held to switch again. Release it when done. Settings and About are skipped.

Move a menu row: select it, hold OK, then use UP and DOWN. Press OK to keep the new order or BACK to cancel.

If the device stops responding: hold UP + BACK together for ten seconds. This restarts the device. In recovery, this combination is unavailable.

6. Updates

Firmware on the device page

  1. Connect USB power or make sure the battery is charged. Open Firmware on the device page and click Check for updates. Read the release notes, then click Update when offered.
  2. Keep the page open. It downloads the update and restarts the device into recovery, a separate mode that installs firmware. Applications and their settings are kept.
  3. When the device asks to update, check the version and press OK within one minute. BACK cancels. Wait for installation, restart and the page's final check. Keep power connected.

Recovery: update or return

Recovery works even when the usual firmware cannot start. It does not run applications. To enter it from the page, choose Device > Enter recovery.

To enter with buttons, hold BACK during a restart and keep it held through the first three seconds. If the device is stuck, hold UP + BACK for ten seconds, then release UP as it restarts and keep BACK held for three more seconds.

While you have internet access, download perinkpheral.bin from the project's latest release. Then open the address on the device's screen. If needed, join perink-recovery and open http://192.168.4.1. Choose the file under Firmware file, click Install firmware and press OK on the device within one minute. Keep the page open during installation. After a successful restart into the usual firmware, perink-recovery disappears. Reconnect to the device's usual network and reopen its page. With no saved network, follow First start. If Wi-Fi was turned off, check the firmware version in About on the device. The recovery page is in English.

To leave without uploading, press BACK, labelled Exit recovery. It tries the installed firmware. If it is damaged or the new firmware fails its checks, the device stays in or returns to recovery. Upload a working file there; the previous firmware is not restored automatically.
